## Context API

_Context API in react is a feature which allows us to share the data globally. It provides global data sharing. It is used to avoid prop drilling._

## Prop Drilling

_In React prop drilling is referred as sending data down the component level by level using props. To avoid this we can use here Context API._

## How to use Context API?

_Here in React we need to create one context first using createContext method. then we need to pass the data to the children component using props as value._

_Create context method returns some components like Provider which is responsible for sending the data to the children component._

_To receive the context data we can use here useContext hook._
