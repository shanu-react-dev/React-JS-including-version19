## Props

_Props stands for properties, it is a way to pass the data from one component to another components. It is unidirectional in nature means it can send the data from parent component to child component only. It is immutable in nature means it can't be changed inside child component._

## Points to remember

_Props can be used in both functional and class components. With functional components, props are passed as arguments to the function. In class based component we have props as an object which is predefined._
